# Dropo 3.1.27 для тестирования

## Как работает маршрутизация

| Сценарий | Ожидаемое поведение |
|---|---|
| «По сервисам», обычный домен | Система разрешает имя через DNS текущей сети. Трафик идёт напрямую, в том числе когда игровой лаунчер обращается к тому же адресу CDN, что и выбранный сервис. |
| «По сервисам», сервису назначен VPN | Новые соединения этого сервиса идут через выбранный VPN. В Windows приложение может получить от Dropo синтетический адрес. |
| Windows, смена VPN → Direct | Если действующий фильтр покрывает новую политику, Dropo применяет её на лету. Новое соединение по ранее выданному адресу получает новый маршрут. Открытые TCP- и UDP-соединения завершают обмен через прежний выход. При расширении области фильтра может потребоваться переподключение. |
| «Всё через VPN» | Публичный трафик и его DNS идут через туннель. Сохранённые политики отдельных сервисов возобновляются при возврате в выборочный режим. Для локальных и рабочих сетей действуют свои правила. |

В диагностике Windows проверяются магазин Steam и службы учётных записей EA app, Epic Games, Battle.net и Riot Client. Для службы учётных записей Dropo проверяет TLS, ответ HTTP 200 и поле `issuer` в документе OpenID. Успешный ответ подтверждает доступность публичной точки входа.

## Что проверено

В изолированной Windows VM с московским сетевым выходом все пять сервисов ответили напрямую и через независимый финский выход. Внешний HTTPS-сервис подтвердил смену IPv4 при переключении VPN → Direct. Windows определила владельца и выход для десяти новых TCP-соединений от пяти тестовых процессов с именами лаунчеров. Открытые TCP- и UDP-сокеты продолжили обмен. На пакетных тестах все 220 сочетаний пяти клиентов и 44 стратегий сохранили байты постороннего трафика.

Для Android прошли автоматические тесты ядра и сетевого моста, включая порядок правил и выбор DNS. Результаты стенда относятся к публичным конечным точкам и тестовым процессам. Проверки реального входа, загрузки игр, матчей и смены мобильной сети остаются задачами тестирования на устройствах.

## Что проверить на устройстве

1. На Windows запустить диагностику, затем открыть свой лаунчер и проверить вход, загрузку и игровую сессию в режиме «По сервисам».
2. Во время загрузки изменить политику выбранного сервиса с VPN на Direct. Проверить непрерывность загрузки и маршрут нового соединения. Затем включить «Всё через VPN» и проверить внешний IP.
3. На Android установить универсальный Preview APK, проверить те же два режима сначала по Wi‑Fi, затем в мобильной сети. При использовании частного или корпоративного DNS проверить доступность своего домена после переключения сети.

К отчёту об ошибке приложить платформу, версию, режим, имя сервиса и результат диагностики. [Контракт маршрутизации](../architecture/ROUTING_CONTRACT.md)
