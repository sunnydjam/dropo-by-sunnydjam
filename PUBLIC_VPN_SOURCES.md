# Бесплатные VPN-источники

Добавлено в Windows 3.0.28. Публичные серверы — необязательный экспериментальный
источник; их доступность и безопасность не гарантируются.

## Как пользоваться

На главном экране или в боковом меню откройте **Источники VPN**.

- **Добавить свою подписку** — личная HTTPS-подписка или отдельный VPN-ключ.
- **Продолжить бесплатно** / добавление бесплатного источника — загрузить публичный список после подтверждения предупреждения.
- Нажмите на выбранный сервер, чтобы открыть поиск по названию или стране.
- **Обновить списки** заново загружает источники; выключатель исключает источник из подключения.
- Удаление последнего источника действительно удаляет его, не восстанавливая старую ссылку из настроек.

Добавление источника не включает VPN само по себе и не изменяет маршруты сервисов.
Если Dropo уже подключена, изменение источников требует переподключения.

## Приоритеты

Включённые источники используются в сохранённом пользователем порядке: тип
источника не переопределяет приоритет. Публичный список **VPN Checker · RU**,
`ru_white_all_part9.txt`, при добавлении помещается в конец, но его можно
переместить выше личных подписок. Новые личные источники также добавляются в конец,
не меняя ручной порядок; сделать новый источник основным можно отдельным действием.

Без личной подписки бесплатный источник может быть единственным источником VPN.
Новые профили не используют публичные серверы без действия пользователя.
Вставленный вручную URL этого же списка также определяется как публичный источник;
параметр `ts` не создаёт второй источник. Личные ссылки не входят в публичный каталог.

На новой установке Windows выбран режим **Всё через VPN**. Перед первым
подключением без источников можно явно согласиться на бесплатный источник или
добавить свою подписку. Выбор режима сам по себе не включает VPN и не означает
согласие на публичные серверы. Сохранённый режим существующей установки и режим
восстановления старых/повреждённых настроек не переводятся в полный VPN.

Отключённое приложение позволяет сохранить полный режим без включённых
источников, удалить или выключить последний источник, выбрать пустой профиль.
Такое состояние требует источника перед запуском: готовый конфиг удаляется из
настроек, а запуск и сборка полного VPN без источника остаются запрещены. Никакого
незаметного перехода на прямой трафик нет. Удалённый или выключенный бесплатный
источник не возвращается без действия пользователя. При активном соединении
изменение, оставляющее полный VPN без источников, не применяется; прежняя цепочка
и соединение восстанавливаются транзакционно.

Одна подписка остаётся одним `VPNSource`. Из неё используется только выбранный
сервер, по умолчанию — первый поддерживаемый сервер публичного списка. Сотни
записей не становятся сотнями автоматических ступеней переключения. Если выбранный
сервер недоступен, монитор проверяет следующий независимый источник, а не соседние
серверы этой подписки. При отсутствии следующего источника сервер выбирается вручную.

Начальный selector и фоновый монитор используют одинаковый порядок, в том числе
при смешении native sing-box и VLESS XHTTP через Xray. Проверки не задерживают
connection-ready gate. Сам факт добавления списка не подтверждает доступность
серверов, разблокировку сайтов или работу Discord voice.

## Надёжность и границы

- Из публичного списка убираются повторы, неподдерживаемые транспорты, некорректные
  порты и очевидные локальные/loopback адреса серверов. Это не аудит операторов VPN.
- Выбор сервера хранится по отпечатку параметров соединения, без названия и
  указанного поставщиком пинга; обновление этих меток не сбрасывает выбор.
- Если выбранный сервер исчез из обновлённого списка, используется первый доступный
  по формату сервер списка; это не результат сетевой проверки.
- При ошибке загрузки используется сохранённая копия, если она есть. Интерфейс
  показывает предупреждение и исходную дату обновления, не выдавая кэш за свежие данные.
- Windows сохраняет прежнюю архитектуру: TUN только для полного VPN; direct-first
  маршрутизация для выборочного режима; один встроенный владелец WinDivert.
- Публичные данные не добавляют правил перехвата. Игры, Steam, LAN и рабочие сети
  сохраняют существующие правила и приоритеты.
- Каталог пока доступен только в Windows. Android не показывает неподдерживаемое
  управление цепочкой бесплатных источников.

## Доверие

Источник данных: [kort0881/vpn-checker-backend](https://github.com/kort0881/vpn-checker-backend).
Список загружается как данные через HTTPS; исполняемые файлы, код проверяющего
сервиса и ключи личных подписок не включаются в приложение из этого проекта.

Публичные серверы управляются третьими лицами, не Dropo. Оператор может наблюдать
метаданные соединений и незашифрованный трафик. Нет гарантии конфиденциальности,
скорости, доступности или снятия географических ограничений. Название RU и цифры
задержки — сведения поставщика, а не свежий замер клиента.

## Проверка разработки

Unit-тесты покрывают opt-in/согласие, пользовательский приоритет, старые URL с `ts`,
дубликаты, отключение и удаление, mixed XHTTP/native bootstrap, сохранение
выбранного сервера, кэш, первый запуск/миграцию и полный режим без готового
источника. Flutter-тесты проверяют сценарии ошибок, поиск в 600
записях и масштаб текста 100–200% на окне 960×640.

Сетевой тест `TestPublicVPNFeedLiveParsing` выполняется только при
`DROPO_TEST_PUBLIC_FEED=1`: скачивает и разбирает список, но не запускает VPN,
не меняет маршруты и не проверяет доступность каждого сервера.
