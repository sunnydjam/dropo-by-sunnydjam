# Бесплатный источник Dropo Free

Windows и Android предлагают бесплатный источник **Dropo Free**. Личные
HTTPS-подписки и поддерживаемые VPN-ключи можно добавлять независимо от неё.
Агрегированные публичные списки больше не предлагаются.

## Добавление и согласие

В разделе **Источники VPN** можно добавить свою подписку или выбрать бесплатный
вариант. Просмотр предложения не загружает подписку, не обращается к её оператору
и не меняет настройки подключения.

После явного согласия приложение проверяет возможности сервиса Dropo. При
`individualVPNProfilesAvailable=true` оно использует случайную защищённую
идентичность установки и получает персональный профиль Free. Вход через Telegram
для этого не требуется. Профиль загружается по HTTPS с проверкой адреса и
сертификата; секретные ключи сохраняются в защищённом хранилище устройства.
Ключи и персональные ссылки не встраиваются в исходники или установщик.

Совместимый прежний сервер без персональных профилей может отвечать через
`GET /v1/vpn/free-source` общей подпиской. Это путь совместимости, а не описание
нового управляемого подключения. Сохранённые старые подписки не удаляются.

Если сервис ещё не настроен, подписка не предоставлена оператором или запрос
не удался, интерфейс честно сообщает, что Dropo Free недоступен. Личную подписку
по-прежнему можно добавить. Нет резервного перехода к стороннему публичному
списку или скрытого разрешения прямого трафика в режиме **Всё через VPN**.

Адрес прежней общей подписки задаётся через `DROPO_FREE_VPN_SUBSCRIPTION_URL`.
Новый профиль выдаётся сервером управления для конкретной установки, а его
состояние синхронизируется с контроллером. Ответы с секретами не кэшируются.
Само наличие настройки не подтверждает работоспособность VPN-серверов.

Турбо предоставляется по правам аккаунта, например после получения подарка или
выдачи администратором. Покупки в текущем рабочем API выключены. По окончании или
отзыве Турбо клиент убирает этот доступ; сервер также проверяет срок и отзыв.
При удалении аккаунта отзыв профилей доставляется в контроллер очередью с повторами.

## Источники, порядок и выбор сервера

Личные источники сохраняют порядок и выбранные серверы. Добавление управляемого
профиля не меняет сохранённый режим подключения или правила сервисов. Доступность
управляемого Турбо зависит от прав аккаунта; Free остаётся бесплатным вариантом.

В ручном режиме сохраняется пользовательский порядок включённых источников.
Автовыбор сравнивает измеренный HTTP-отклик между независимыми источниками; это
не игровой пинг и не тест скорости скачивания. Соединение не переключается
постоянно из-за небольших колебаний задержки.

Одна подписка — один источник. По умолчанию используется первый поддерживаемый
сервер поставщика или выбранный пользователем сервер. Соседние серверы одной
подписки не становятся автоматическими ступенями резервирования. При отказе
проверяется следующий независимый источник, а сервер внутри подписки выбирается
вручную.

Добавление не включает VPN само по себе. В Android изменение применяется после
подтверждённого отключения; Windows использует транзакционное переподключение.
Полный VPN без включённого пригодного источника не запускается. Сохранённый выбор
режима пользователя не переопределяется.

## Ранее сохранённые публичные списки

Записи **VPN Checker · RU**, сохранённые в старых версиях, не удаляются и не
выключаются автоматически: это могло бы оборвать рабочее соединение. В списке
показано предупреждение, что этот источник больше не предлагается; удалить его
можно вручную через **Ещё**. Старый API добавления публичного каталога больше
не создаёт такие записи. Обновление не добавляет новые сторонние каталоги.

Распознавание старой записи сохраняет её порядок и выбранный сервер. Личная
подписка не становится Dropo Free по совпадению адреса: управляемая метка ставится
только отдельным действием добавления после согласия.

## Доверие и проверки

Бесплатность не гарантирует скорость, конфиденциальность или доступность.
Оператор VPN может видеть метаданные соединений и незашифрованный трафик.
Подписка обрабатывается как данные; исполняемые файлы и код оператора не загружаются.
LAN, рабочие сети и существующая архитектура маршрутизации остаются без изменений.

Тесты используют фиктивные адреса и локальные подмены транспорта, без загрузки
реальной приватной подписки. Проверяются согласие до сетевого запроса, недоступный
сервис, отсутствие ссылки в каталоге и ошибках интерфейса, сохранение ручного
порядка, поддерживаемые серверы, отказ от локальных адресов и сохранение старых
записей с предупреждением. Проверки источников, поиска сервера и масштаба текста
остаются частью тестового набора Windows и Android.
