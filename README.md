# Dropo by sunnydjam

Windows-first VPN-клиент с выборочной маршрутизацией сервисов. Проект позволяет
отправлять выбранные сервисы через VPN, оставляя игры, сайты и остальной трафик
на прямом подключении. Также доступен режим полного VPN и экспериментальный
встроенный режим обхода блокировок.

## Как работает маршрутизация

На главной странице доступны два основных режима.

### Выборочные маршруты

Для каждого добавленного сервиса можно выбрать политику:

- `Напрямую` — сервис не использует VPN;
- `Через VPN` — только трафик этого сервиса уходит в выбранный VPN-источник;
- `Обход (Zapret)` — локальная стратегия без VPN; её статус и ограничения
  зависят от конкретного сервиса и сети провайдера.

По умолчанию доступны YouTube, Discord, Instagram и ChatGPT. Быстрый список
открывается кнопкой **Настроить сервисы** на главной или через **Настройки →
Сервисы**, а дополнительные сервисы добавляются отдельной кнопкой.

Для чистой Windows-установки используется проверенный стартовый профиль:

| Сервис | Начальный маршрут | Причина |
| --- | --- | --- |
| YouTube | `Обход (Zapret)` | Не требует VPN; стратегия подбирается для текущей сети |
| Discord | `Через VPN` | Стабильно охватывает web, приложение и voice/video |
| Instagram | `Через VPN` | Сервис требует полноценного VPN-маршрута |
| ChatGPT | `Через VPN` | Сервис требует полноценного VPN-маршрута |
| Игры, Steam и остальные сервисы | `Напрямую` | Не получают лишний маршрут и дополнительный пинг |

Обновление не заменяет уже сохранённые политики: явный выбор пользователя
остаётся авторитетным.

Главный контракт этого режима: **невыбранный и неуверенно распознанный трафик
проходит напрямую без изменения**. Не требуется добавлять каждую игру или сайт
в исключения.

### Всё через VPN

Весь обычный интернет-трафик направляется через активный VPN-источник. Этот
режим предназначен для ситуаций, когда выборочная маршрутизация не нужна.
Удалённый DNS-over-HTTPS также идёт через VPN; без включённого VPN-источника
режим не запускается. Локальные адреса и явно настроенные рабочие WireGuard-сети
сохраняют приоритет, чтобы не терять доступ к LAN и корпоративным ресурсам.

### Приоритеты

```text
Рабочая сеть / WireGuard overlay
        ↓
Явная политика сервиса: Direct / VPN / экспериментальный обход
        ↓
Нераспознанный или невыбранный трафик: Direct
```

Рабочие сети и частные адреса имеют приоритет над публичным VPN. Явный выбор
пользователя не заменяется автоматической стратегией.

## Архитектура Windows

- Flutter отвечает за интерфейс;
- Go core управляет профилями, VPN-источниками и жизненным циклом соединения;
- sing-box использует proxy-only сессию для выбранных сервисов и TUN для
  режима всего трафика (а также настройки Hide-RU);
- встроенный `app/trafficorchestrator` является единственным Dropo-владельцем
  WinDivert;
- полный неизменяемый `TrafficPlan` применяется атомарно;
- классификация использует домены, процесс, CIDR с обязательным контекстом,
  TCP/UDP-порты, TLS SNI и QUIC Initial;
- неизвестный трафик и ошибки классификации обрабатываются fail-safe: пакет
  проходит без изменения.

Dropo не запускает скачанные anti-DPI-скрипты, Lua/Cygwin runtime или внешние
командные стратегии в Windows traffic path. Внешние проекты обхода используются
только как исследовательские источники, перечисленные в
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Подробный контракт маршрутизации находится в
[ROUTING_CONTRACT.md](ROUTING_CONTRACT.md).

## VPN-источники

Поддерживаются подписки и отдельные конфигурации VLESS, VMess, Trojan,
Shadowsocks, Hysteria2, TUIC и WireGuard.

- одна подписка считается одним VPN-источником;
- пользователь может выбрать поддерживаемый узел внутри источника;
- fallback выполняется между независимыми источниками;
- порядок источников и выбранные политики сохраняются локально;
- секретные ссылки и ключи не записываются в обычные журналы.

### Бесплатный VPN-резерв (по желанию)

В Windows 3.0.28 добавлен каталог публичных серверов: **Источники VPN →
Добавить бесплатный резерв**. Личные подписки имеют приоритет; список VPN Checker
RU используется последним и включается только по желанию пользователя.
Это сторонние серверы без гарантии доступности. Подробности, ограничения и
инструкция: [Бесплатные VPN-источники](PUBLIC_VPN_SOURCES.md).

### Надёжность соединения — 3.0.31

Полный VPN использует только VPN-кандидаты и отдельный DNS-кэш, а старые
конфигурации автоматически перестраиваются перед подключением. Смена режима,
подписки, источника или узла выполняется как одна транзакция с восстановлением
предыдущего состояния при ошибке. Ручное отключение всегда сильнее фонового
переподключения.

В Windows удалён отдельный `tg-ws-proxy`: Dropo больше не открывает Telegram и
не подменяет его настройки. Если proxy был сохранён старой версией, интерфейс
покажет отдельную подсказку и откроет настройки Telegram только по нажатию
пользователя.

### Основа интерфейса «Атлас» — 3.0.29

В 3.0.29 появилась тёмно-зелёная палитра с планетой, явным статусом подключения,
активным источником и двумя режимами. Состояния различаются текстом, а не только
цветом; полный VPN не стирает сохранённые маршруты. В 3.0.30 эта основа сохранена,
а расположение элементов упрощено. Подробности:
[Улучшения интерфейса](UI_IMPROVEMENTS.md).

### Минималистичный интерфейс — 3.0.30

Главная упрощена: анимированная планета с кнопкой подключения, текущий
источник, два режима и вход **Настроить сервисы**. В основном меню только
**Подключение** и **Настройки**. Подписки, четыре основных сервиса и добавление
остальных доступны без технических параметров. Профили, рабочие сети,
экспериментальный обход и диагностика сохранены в дополнительных разделах.

Windows-окно рассчитано на 700×500; узкие экраны и увеличенный текст используют
адаптивную прокрутку, а не фиксированное соотношение сторон. Существующие
маршруты не меняются при открытии настроек. Android сохраняет отдельный маршрут
«Авто» и ограничения изменения настроек при активном VPN.
Android-пакет не входит в Windows-выпуск и проходит отдельный release gate.

## Discord и приложения

Discord классифицируется не только как сайт. Учитываются web/API, gateway,
STUN/discovery и динамические voice/video/Go Live endpoints. Успешное открытие
сайта не считается доказательством исправности голосового канала.

Начиная с версии `3.0.30` для Discord рекомендуется `Через VPN`. Встроенный Zapret
оставлен для ручных экспериментов: он может открыть web/API, но Discord voice
использует отдельные gateway-соединения, альтернативные TCP-порты и динамический
двусторонний UDP media path. Изменение DPI у провайдера способно нарушить одну
из этих частей независимо от остальных.

Маршрутизация рассчитана как на браузеры, так и на приложения. Невыбранные игры
и клиенты, включая Steam, должны сохранять прямой маршрут.

Технические границы и правила экспериментального режима описаны в
[EXPERIMENTAL_ZAPRET.md](EXPERIMENTAL_ZAPRET.md).

## Установка и выпуск

Текущий Windows-выпуск публикуется как
[`v3.0.31`](https://github.com/sunnydjam/dropo-by-sunnydjam/releases/tag/v3.0.31).
Не выдавайте сборки upstream за сборки этого fork и не скачивайте исполняемые
файлы из случайных источников.

Windows release содержит:

- `dropo-Windows-Setup-x64.exe` — автономный установщик;
- `dropo-Windows-Portable-x64.zip` — portable-версию без установки.

Установленная Windows-версия по умолчанию проверяет только стабильные GitHub
Releases этого репозитория. Если найден новый выпуск, Dropo скачивает точный
installer asset, проверяет заявленный размер и GitHub SHA-256, выполняет тихое
обновление поверх текущей установки и открывает окно новой версии. Начиная
с установщика 3.0.29, запуск выполняется напрямую, в том числе после тихого
обновления старого клиента: нажимать «Готово» или открывать ярлык не нужно.
Повторное подключение VPN зависит от сохранённых настроек, а не от открытия
окна. Эту функцию обновления можно
отключить в разделе `Настройки → Приложение → Обновления`. В 3.0.29 проверка
обновлений находится прямо в настройках. Portable-версия показывает новый
архив, но не заменяет собственные запущенные файлы автоматически.

До появления доверенной Authenticode-подписи тестовые Windows-артефакты будут
отмечаться как unsigned. Отключать Defender или добавлять исключения не нужно.
Политика описана в [CODE_SIGNING_POLICY.md](CODE_SIGNING_POLICY.md).

## Сборка Windows

Требования:

- Go 1.25.13;
- Flutter 3.47.1 stable;
- Visual Studio Build Tools 2022 с Desktop development with C++;
- Windows 10/11 SDK;
- Inno Setup 7.1.0.

SDK принято хранить отдельно от репозитория. Общий каталог задаётся переменной:

```powershell
[Environment]::SetEnvironmentVariable(
    "DROPO_TOOLCHAIN_ROOT",
    "E:\Development\Toolchains\Dropo",
    "User"
)
```

Откройте новое окно PowerShell и выполните:

```powershell
git clone https://github.com/sunnydjam/dropo-by-sunnydjam.git
cd dropo-by-sunnydjam
git switch Dzhamuha-develop
flutter --version
go version
pwsh -File .\scripts\build\build.ps1 -AppOnly
```

Результат появится в `release/dropo-<version>-<commit>/`.

Проверка уже собранного Windows-релиза (подставьте созданный каталог):

```powershell
pwsh -File .\tools\preflight-release.ps1 `
    -ReleaseFolder .\release\dropo-<version>-<commit> `
    -SkipInstall `
    -SkipLifecycleSmoke
```

Запуск `preflight-release.ps1 -Build` проверяет полный набор платформ и поэтому
дополнительно требует Android SDK и настроенный Flutter Android toolchain.
Lifecycle smoke требует PowerShell с правами администратора.

## Диагностика

Логи Windows находятся в `%LOCALAPPDATA%\dropo\logs`.

Для подробной packet-диагностики можно временно задать
`DROPO_TRAFFIC_PACKET_DEBUG=1` или создать `traffic-debug.txt` рядом с launcher.
Публикуя отчёт, удалите VPN-ключи, subscription URL и персональные адреса.

## Конфиденциальность и безопасность

В приложении нет рекламы, телеметрии и автоматической отправки crash reports.
Профили, ключи, настройки и логи остаются на устройстве. Сетевые запросы
выполняются только для работы выбранных подключений, проверок доступности,
обновлений и явно вызванной диагностики. Подробнее:
[PRIVACY.md](PRIVACY.md).

Windows-пакет включает file-level runtime manifest, SPDX SBOM и provenance.
Версии основных runtime-компонентов и их SHA-256 закреплены в исходниках.
