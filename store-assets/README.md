# Материалы dropo для публикации

Оформление обновлено 21 октября 2026 года: тёмно-зелёная планета с орбитой и маленький летающий герой-доктор.
Скриншоты настоящего интерфейса версии 3.0.25 сохранены внутри нового оформления.
Готовый комплект: `dropo-publication-assets.zip`.

| Поле в Google Play Console | Файл / папка | Формат |
| --- | --- | --- |
| App icon | `app-icon-512.png` | 512×512, 32-bit PNG, sRGB, непрозрачный квадрат |
| Feature graphic, русский | `ru-RU/feature-graphic-1024x500.png` | 1024×500, 24-bit PNG, sRGB, без alpha |
| Phone screenshots | `ru-RU/phone/` | 4 изображения 1080×1920, 9:16 |
| 7-inch tablet screenshots | `ru-RU/tablet-7/` | 4 изображения 1920×1080, 16:9 |
| 10-inch tablet screenshots | `ru-RU/tablet-10/` | 4 изображения 1920×1080, 16:9 |
| Chromebook screenshots | `ru-RU/chromebook/` | 4 изображения 1920×1080, 16:9, Android-интерфейс |
| Материалы Windows для сайта / desktop-публикации | `ru-RU/windows/` | 4 изображения 1920×1080, 16:9, Windows-интерфейс |

В каждое поле загружаются отдельные PNG из соответствующей папки. Windows-снимки
предназначены для Windows; в Chromebook-разделе используйте `chromebook`.
ZIP нужен для передачи комплекта, в Play Console его целиком не загружают.
Все скриншоты — 24-bit PNG без прозрачности. Размеры, вес и SHA-256 каждого
файла записаны в `manifest.json`. Launcher-иконки Android, значок окна Windows
и три состояния трея обновлены на основе `app-icon-512.png`.
Серый означает отключение, зелёный — подключение, красный — ошибку соединения.
Экспорт размеров: `python tools/prepare-app-icons.py` (требуется Pillow).
Исходники состояний и промпты: [source/APP_ICONS.md](source/APP_ICONS.md).

## Происхождение и воспроизведение

Скриншоты получены Flutter-рендерером из настоящих виджетов
`flutter_app/lib/main.dart`. Полный интерфейс без обрезки размещён поверх
иллюстрированных зелёных фонов с планетой и героем-доктором. Интерфейс и его
надписи не перерисовывались; рекламных надписей и рамок устройств нет.
Оригинальные снимки сохранены в `source/screenshots/`; экспорт всегда берёт их,
поэтому повторный запуск не уменьшает уже оформленные изображения.
Используются изолированные демонстрационные данные bridge:
профили, подключённое состояние, задержки и статистика заданы для съёмки.
Это демонстрация интерфейса, а не измерения скорости или доказательство
VPN-подключения на физических устройствах. Личные конфиги, ключи и URL подписок
не использовались. У планшетов и Chromebook включена Android-навигация,
у Windows — боковое меню. Размеры окна до экспорта: телефон 432×768,
7″ 960×540, 10″ 1280×720, Chromebook 1440×810, Windows 1280×720.

Иконка, feature graphic и фоны скриншотов подготовлены встроенным инструментом image_gen.
Исходники и точные промпты сохранены в `source/`; финальные размеры и цветовые
форматы экспортируются локально. Утверждённая иконка — тёмно-зелёная планета
с орбитой и маленький летающий герой-доктор, без текста, внешней обводки
и заранее скруглённых углов. Предыдущая графика сохранена в
`source/previous-branding-2026-10-21/`; варианты из `icon-options-green/`
не входят в публикационный ZIP.

Из корня репозитория:

```powershell
Push-Location flutter_app
flutter test tool/capture_store_assets_test.dart --reporter expanded
Pop-Location
powershell -NoProfile -File tools/prepare-store-assets.ps1
```

Экспорт повторно создаёт только файлы этого комплекта. Он не запускает VPN,
не публикует приложение и не меняет настройки установленного клиента.

## Проверенные требования Google Play

- [Иконка: 512×512, 32-bit PNG, до 1024 KB, квадрат без внешней тени и скругления](https://developer.android.com/distribute/google-play/resources/icon-design-specifications).
- [Feature graphic: 1024×500, JPEG или 24-bit PNG без alpha; скриншоты и требования к большим экранам](https://support.google.com/googleplay/android-developer/answer/9866151).
- [Metadata policy: достоверный интерфейс, без заявлений о рейтингах, наградах и рекламных обещаний](https://support.google.com/googleplay/android-developer/answer/9898842).

Технические проверки файлов выполнены локально. Загрузка в Play Console и
модерация Google в эту подготовку не входили.
