# Экспериментальный режим Zapret

Этот документ описывает статус встроенного обхода в Dropo by sunnydjam
`3.0.27`. Он нужен, чтобы пользователь мог отличить проверенный маршрут от
экспериментальной сетевой стратегии и понимать границы автоматической проверки.

## Текущий статус

| Сервис | Статус | Рекомендуемый маршрут |
| --- | --- | --- |
| YouTube | General ALT работает на проверенной сети; другие сети могут требовать другую стратегию | `Обход (Zapret)` с автоподбором или ручной стратегией |
| Discord web/API | Некоторые стратегии могут работать | Для стабильной работы — `Через VPN` |
| Discord приложение | Зависит от gateway и текущего DPI провайдера | `Через VPN` |
| Discord voice/video/Go Live | Zapret пока не считается стабильным | `Через VPN` |

Zapret не является VPN: он не меняет публичный IP и не создаёт общий туннель.
Dropo изменяет только строго классифицированные начальные пакеты выбранного
сервиса, чтобы не затрагивать игры, Steam и посторонние сайты.

## Почему стратегия может перестать работать

DPI-фильтрация не является постоянным протоколом. Провайдер может изменить
оборудование, сигнатуры, таймауты или правила обработки TLS/QUIC. Рабочая вчера
последовательность fake/split/disorder может перестать работать без изменения
Dropo.

Для Discord одной проверки сайта недостаточно. Сервис использует несколько
независимых плоскостей:

- HTTPS web/API и CDN;
- постоянный gateway WebSocket;
- альтернативные TLS-порты `2053`, `2083`, `2087`, `2096`, `8443`;
- STUN/discovery;
- динамический двусторонний UDP для voice/video/Go Live.

Общий Cloudflare/CDN IP также может одновременно обслуживать Discord и
посторонний сервис. Dropo намеренно не применяет стратегию ко всему такому IP:
это могло бы снова сломать Steam, игры или обычные сайты. Требуется подтверждение
доменом, процессом или media fingerprint.

## Что означает «экспериментальный»

Экспериментальная функция доступна пользователю и защищена теми же границами
маршрутизации, но ещё не имеет достаточного подтверждения на разных
провайдерах и для всех протокольных целей сервиса. Для Discord это означает:

- успешный web-запрос не считается доказательством рабочего voice;
- синтетическая проверка не может полностью воспроизвести живой медиасеанс;
- ручная стратегия может быть рабочей только для части сервиса;
- результат может измениться после обновления сети провайдера;
- неуспешный Zapret не должен расширять перехват на чужой трафик.

Автоподбор Discord поэтому также помечен экспериментальным. Dropo не сохраняет
кандидата как полностью рабочий, пока не получит устойчивое двустороннее media
evidence. При наличии VPN стабильным выбором остаётся явная политика
`Через VPN`.

## Реализация и безопасность

Windows-версия использует только встроенный `app/trafficorchestrator` и один
WinDivert handle. Профили Flowseal 1.10.2 адаптированы в типизированные,
ограниченные действия Dropo; внешние BAT/Lua/Cygwin-процессы не запускаются.

Основные ограничения:

- неизвестный или слабо классифицированный пакет проходит без изменения;
- service CIDR не является самостоятельным доказательством сервиса;
- Discord на общем IP требует process/domain/media context;
- рабочие сети и частные адреса имеют приоритет;
- Steam и игровые порты отсутствуют в Discord discovery filter;
- новый `TrafficPlan` проверяется целиком и применяется атомарно;
- явный пользовательский выбор Direct/VPN/Zapret не заменяется автоподбором.

## Практическая рекомендация для 3.0.27

Используйте режим `Выбранные сервисы`:

1. YouTube — `Обход (Zapret)`.
2. Discord — `Через VPN`.
3. Instagram и ChatGPT — `Через VPN`.
4. Игры, Steam и остальные сервисы — `Напрямую`.

Для проверки Discord Zapret полностью завершите Discord через системный трей,
выберите стратегию, подключите Dropo и только затем снова запустите Discord.
Не публикуйте VPN-ключи, subscription URL или полные необработанные логи в
GitHub Issues.
